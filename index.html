Data flow

NCPOR / NPDC dataset→Data processing→Backend API→Digital twin→AI / ML analytics→Dashboard

Publicly available NCPOR/NPDC datasets are used as the environmental data layer of the prototype. Operational station parameters are simulated for demonstration.

Note: NCPOR/NPDC reference datasets are used for prototype demonstration. The current prototype does not claim direct live access to restricted or real-time NCPOR systems. Live station telemetry can be integrated through authorized data interfaces during deployment.
